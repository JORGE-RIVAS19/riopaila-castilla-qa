# Proyecto: Asistente de conocimiento de Riopaila Castilla

## Propósito
Construir, módulo a módulo, un asistente corporativo sobre información pública de Riopaila Castilla S.A.
El Módulo 1 entrega la base de conocimiento (scraping Medallion) y un sistema Q&A con prompt engineering.

## Stack
Python 3.13 · uv · requests + BeautifulSoup + lxml + trafilatura · LangChain (LCEL) · Ollama (Llama 3.2) ·
Gemini/OpenAI opcionales · Streamlit · pytest · Ruff.
